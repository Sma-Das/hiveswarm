# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Expert application-security operators conducting authorized assessments. The primary environment is a laptop during long working sessions. Larger desktops and narrow screens must remain usable.

## Product Purpose

HiveSwarm lets an operator define assessment boundaries, supervise specialist executions, review one-time approvals, and trace findings to evidence. The operator must be able to distinguish pending decisions, execution state, and supported findings without interpreting decorative activity.

## Positioning

A provider-neutral planner proposes specialist work. Deterministic local policy decides whether work is within the operator's authority. Typed evidence connects assets, findings, specialist executions, and reports.

## Capabilities and Constraints

Preserve project isolation, lifecycle controls, scope rules, explicit deny precedence, manifest registration, capability review, and one-time approvals. Keep the default in-memory, simulated experience useful without credentials, Docker authority, or real targets. Do not imply authenticated multi-user access or production-grade destination enforcement.

## Brand Commitments

The operator authorizes a complete visual and workflow redesign. Vercel, Wiz, Apple, and recent Cloudflare sites are references for clean design, technical readability, and interaction quality. The implementation retains the HiveSwarm name. No existing palette or mark is fixed.

## Evidence on Hand

The API supplies project-partitioned dashboard data, approvals, logs, artifacts, and reports. Built-in demonstration state is simulated. Never invent assessment results, coverage, execution progress, identity, or capabilities.

## Product Principles

- Make human decisions conspicuous and reviewable.
- Keep run state and data freshness truthful.
- Make findings lead back to evidence.
- Prefer readable working space to permanently visible secondary panels.

## Accessibility & Inclusion

Keyboard-operable navigation, dialogs, forms, and inspection. Visible focus, readable contrast, reduced motion, and usable narrow layouts are required.
